## About

I work across the full stack — React and Next.js on the frontend, React Native/Expo for mobile, and Node.js/Express on the backend — building products for real clients rather than tutorial projects. My work typically starts with a client's idea and ends with a deployed, working system: authentication, APIs, databases, dashboards, and everything in between.

I've built and shipped systems that include sign-in with Apple and Google, push notifications, real-time features, and admin dashboards with role-based access — the parts of a product that separate "it runs on my machine" from something people actually use.
